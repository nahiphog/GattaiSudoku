HUMAN-STYLE WALKTHROUGH

Start at the overlap.

  1. Scan for naked singles. In each row, column, and 3×3 box, a cell with one remaining candidate can be placed immediately.
  2. Use hidden singles. A digit that can appear in only one cell of a unit is forced even if that cell has other candidates.
  3. Re-scan both boards. Every shared placement updates one row, column, and box in each board. This is the engine of a Gattai solve.
