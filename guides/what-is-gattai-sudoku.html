What Is Gattai Sudoku? Rules & Beginner's Guide

A complete introduction to the overlapping two-grid Sudoku variant — also called Gattai-2 or simply Gattai.

Gattai Sudoku (from the Japanese gattai, meaning "combine" or "merge") is a Sudoku variant where two standard 9×9 grids overlap in a shared 6×6 region. Every normal Sudoku rule applies to both grids simultaneously, and the overlapping cells must satisfy both grids at once.

Grid layout

Instead of one 9×9 square, a Gattai puzzle uses two overlapping 9×9 grids arranged on a 12×12 board, with two inaccessible 3×3 regions in the top-right and bottom-left corners:

  • Grid 1 (top-left): occupies columns 1–9 of rows 1–9
  • Grid 2 (bottom-right): occupies columns 4–12 of rows 4–12
  • Shared 6×6: the area where both grids overlap (rows 4–9, columns 4–9)

The board has 126 active cells (81 + 81 − 36 shared cells). The 18 remaining positions form the two inaccessible 3×3 corners and are never filled.

Basic rules

  1. Every row in each 9×9 grid must contain the digits 1–9 exactly once.
  2. Every column in each 9×9 grid must contain the digits 1–9 exactly once.
  3. Every 3×3 box in each 9×9 grid must contain the digits 1–9 exactly once.
  4. The shared 6×6 region belongs to both grids simultaneously. A digit placed in a shared cell must satisfy the row, column, and box constraints of both grids.
Key difference from standard Sudoku: In the shared region, cells have two competing sets of row, column, and box neighbours. A candidate digit might be valid in Grid 1 but already present in a Grid 2 house that crosses the same cell — and vice versa.

Generate a puzzle

The homepage offers two generation methods. Both check that displayed results have exactly one solution.

  • Digging: starts from a complete grid and removes clues. Single cell mode removes one clue at a time. Dual cell mode removes 180° rotational pairs across the whole 12×12 board: (row, column) maps to (13 − row, 13 − column).
  • Stopping controls: optionally set a time cap or Stop at givens, or select Halt. Stop at givens prevents removals that would go below the chosen count; it does not guarantee reaching that count. The time cap and Halt are checked between removal attempts, so a running uniqueness check can delay stopping.
  • Build a puzzle: mark green cells that must contain clues and red cells that must stay blank. Choose 0–30 maximum extra clues (default 30). The builder adds individual clues from a generated solution and retries with new solutions if needed. These marks select positions, not specific digit values; restrictive settings may require Halt and revised constraints.

Only Dual cell digging enforces rotational symmetry. There is no fixed clue-count range or guaranteed logic-only solve path.

Verify and explore the solution

After generation, the difficulty rating and solution walkthrough appear automatically below the puzzle. To check your own puzzle, use Verify a solution: enter clues or import a 144-character string, select Check uniqueness, then evaluate a uniquely solvable result.

Ratings run from Beginner through Easy, Medium, Tricky, Hard, Unfair, Extreme, and Nightmare. They depend on the current walkthrough's techniques and cumulative score, not simply the clue count. If the named logical techniques stall, the walkthrough labels its fallback placements Trial and error.
