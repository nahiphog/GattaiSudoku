How to Solve Gattai Sudoku

The techniques currently used in the solution walkthrough, with their actual scores.

A house is a nine-cell row, column, or 3×3 box in either grid. Two cells see one another when they share a house. For a shared cell, check both grids' row and column constraints; the overlapping boxes contain the same physical cells.

Open the walkthrough

  1. On the generator, create a puzzle using Digging or Build a puzzle.
  2. When generation finishes, the difficulty rating, solution walkthrough, and technique tally appear directly below the puzzle.
  3. Use the first, previous, next, and last step controls to inspect the deductions. The technique tally lists the step numbers where each technique occurs.

For your own puzzle, open Verify a solution, enter clues directly or paste a 144-character string and select Import string. The string covers the 12×12 board row by row; use digits 1–9 for clues and dots for blanks, including the two inaccessible corners. Select Check uniqueness, then Evaluate puzzle difficulty if the solution is unique.

The verifier is a clue-entry and evaluation tool. Walkthrough candidates are calculated automatically; relevant highlights and explanations depend on the technique.

Named logical techniques

The walkthrough follows a fixed search order and returns to the simplest techniques after each successful step. Fish and Pointing/Claiming are searched within each individual grid. Wings and Remote Pairs use the combined Gattai peer relationships, so they can connect cells across the overlap.

  • Full HouseScore: 4A row, column, or 3×3 box has exactly one empty cell. Fill it with the missing digit.
  • Naked SingleScore: 4An empty cell has only one remaining candidate after applying all of its peer constraints and prior eliminations.
  • Hidden SingleScore: 14A missing digit has only one possible cell in a row, column, or box, even if that cell has other candidates.
  • PointingScore: 50Within a box, all candidates for a digit lie in one row or column. Remove that digit from the rest of that row or column in the same 9×9 grid.
  • ClaimingScore: 50Within a row or column, all candidates for a digit lie in one box. Remove that digit from the rest of that box.
  • Naked PairScore: 60Two cells in one house have only the same two candidates between them. Remove those digits from other cells in the house.
  • Hidden PairScore: 70Two digits can occur only in the same two cells of a house. Remove other candidates from those cells.
  • Naked TripleScore: 80Three cells in one house have only three distinct candidates between them. Individual cells need not contain all three. Remove those digits from the other cells.
  • Hidden TripleScore: 100Three digits are confined to three cells in one house. Remove other candidates from those cells.
  • Naked QuadScore: 120Four cells in one house have only four distinct candidates between them. Remove those digits from the other cells.
  • Hidden QuadScore: 150Four digits are confined to four cells in one house. Remove other candidates from those cells.
  • X-WingScore: 140In two rows of one grid, a digit is confined to the same two columns. Remove it from the other cells in those columns. The transposed column-to-row pattern also works.
  • SwordfishScore: 150A digit in three rows is confined to three columns, with two or three candidate positions per selected row. Remove it from the other cells in those columns; the transposed pattern also works.
  • JellyfishScore: 160A digit in four rows is confined to four columns, with two to four candidate positions per selected row. Remove it from the other cells in those columns; the transposed pattern also works.
  • SkyscraperScore: 130Two rows each have exactly two positions for a digit, with one position in each row sharing a column. At least one of the two other endpoints must contain the digit, so eliminate it from cells seeing both endpoints. Columns can be used instead of rows.
  • 2-String KiteScore: 150A row and a column each have exactly two positions for a digit. One endpoint from each link lies in the same box. At least one of the two other endpoints must contain the digit, allowing eliminations from cells seeing both.
  • W-WingScore: 150Two non-peer bivalue cells contain the same pair. A strong link for one digit (the only two positions in a house) connects the wings through their peers. The other digit can be removed from cells seeing both wings.
  • XY-WingScore: 160A pivot with candidates X/Y sees wings X/Z and Y/Z, each with exactly two candidates. Either pivot value forces Z into one wing, so remove Z from cells seeing both wings.
  • XYZ-WingScore: 180A pivot with candidates X/Y/Z sees bivalue wings X/Z and Y/Z. Remove Z from cells seeing the pivot and both wings.
  • Remote PairsScore: 200An even-length chain of at least four cells all contains the same two candidates. Consecutive cells see one another, forcing alternating values. The endpoints must be opposite, so remove either pair digit from cells outside the chain that see both endpoints. The walkthrough highlights the chain and lists the eliminations.

For the precise search order, technique floors, and cumulative thresholds, see Difficulty Scoring.

When logic stalls

Generated puzzles are checked for a unique solution, but are not guaranteed to be solvable by this repertoire alone. When all implemented named techniques stall, the walkthrough inserts a digit from the verified solution, labels it Trial and error, then returns to logical deductions. Each such step scores 10,000 points and makes the final rating Nightmare.

Forcing Chains, Colouring, Empty Rectangle, and Almost Locked Sets are not currently named techniques in this walkthrough. A search step does not prove that a different human deduction is impossible.

Strategy tips for Gattai

  1. Scan both grids. A placement in the overlap can remove candidates in both grids at once.
  2. Use nine-cell houses. A full 12-cell horizontal or vertical span is not a Sudoku house; each grid has its own nine-cell rows and columns.
  3. Keep all remaining candidates in mind. In the overlap, a candidate must satisfy both grids' constraints.
  4. Read the step explanation. Check which cells and candidates establish the pattern before moving to the next step.
