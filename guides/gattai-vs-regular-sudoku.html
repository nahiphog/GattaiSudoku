Gattai Sudoku vs Regular Sudoku

How this site's overlapping two-grid format changes the board, constraints, and solving workflow.

The digits and nine-cell house rules are familiar from standard Sudoku. The difference is that two grids share cells, so a deduction in one grid can affect the other.

How the overlap works

Grid 1 occupies rows 1–9 and columns 1–9. Grid 2 occupies rows 4–12 and columns 4–12. Their shared region is rows 4–9 and columns 4–9, giving 81 + 81 − 36 = 126 active cells.

A shared cell belongs to a nine-cell row and column in each grid. Those row and column segments overlap but are not identical. Its 3×3 box is physically the same box in both grids. The entire 12-cell span is not one house: the 1–9 rule applies separately to each grid's nine-cell houses.

Clue symmetry on this site

Single cell digging removes clues individually and does not enforce symmetry. Dual cell — rotational pairs removes partners related by a 180° rotation of the whole 12×12 board: (row, column) maps to (13 − row, 13 − column), using one-based board coordinates. This is not a separate rotation inside each 9×9 grid.

Build a puzzle lets you mark required clues and required blanks, then adds individual clues until it finds a unique solution within the selected extra-clue allowance. It does not enforce rotational symmetry.

Clue counts and difficulty

The site does not establish a minimum possible clue count for this Gattai format. A small clue count does not by itself establish a difficulty tier, and extra overlap constraints do not guarantee that Gattai is easier than standard Sudoku.

The current evaluator rates its own walkthrough using technique scores and floors. Generation guarantees uniqueness for displayed results, but not completion by the named logical techniques. Read Difficulty Scoring for the rating rules and search fallback.
